# src-acme-shop

Source code of shop by acme, owned by the customer.

- Commit to `main` (directly, or through your mirror). Every push is built by the platform pipeline.
- Edit `VERSION` and `app/config.json` to make a visible release.
- History can't be rewritten: force-pushes and branch deletion are blocked.
- Deployments happen in `deploy-acme-shop`.
